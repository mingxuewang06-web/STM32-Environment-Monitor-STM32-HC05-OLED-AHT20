# STM32 环境监测与蓝牙报警系统

## 项目简介

本项目基于 STM32F103C8T6，使用 AHT20 采集环境温湿度，使用 GL5516 光敏电阻模块采集光照电压，通过 0.96 寸 I2C OLED 进行本地多页面显示，并通过 HC-05 蓝牙模块实现手机端数据监测和远程控制。

系统支持本地编码器切换页面、按键进入阈值编辑、光照阈值报警、蜂鸣器自动/手动控制，以及手机端通过蓝牙指令切换页面、修改阈值和控制蜂鸣器工作模式。

## 功能特点

* AHT20 温湿度采集与 OLED 显示
* GL5516 光照电压采集与阈值判断
* OLED 多页面显示温度、湿度、光照和阈值
* EC11 编码器本地切换页面
* 按键进入阈值编辑模式，编码器调整光照报警阈值
* 光照低于阈值时蜂鸣器自动报警
* HC-05 蓝牙串口上传环境数据到手机
* 手机发送指令控制页面、阈值和蜂鸣器模式
* 支持蜂鸣器自动模式和手动模式切换

## 引脚连接

|模块|模块引脚|STM32 引脚|说明|
|-|-|-|-|
|OLED|SCL|PB6|软件 I2C 时钟线|
|OLED|SDA|PB7|软件 I2C 数据线|
|AHT20|SCL|PB6|与 OLED 共用 I2C 总线|
|AHT20|SDA|PB7|与 OLED 共用 I2C 总线|
|GL5516|A0|PA0|ADC1 通道 0|
|HC-05|TXD|PA10|USART1\_RX|
|HC-05|RXD|PA9|USART1\_TX|
|HC-05|GND|GND|共地|
|HC-05|VCC|3.3V/5V|视模块小板供电要求而定|
|蜂鸣器|IN|PB10|低电平触发|
|EC11|A|PB12|编码器 A 相|
|EC11|B|PB13|编码器 B 相|
|按键|OUT|PA5|下降沿检测|

> 注意：HC-05 的 TXD 接 STM32 的 RX，HC-05 的 RXD 接 STM32 的 TX。普通通信模式下 EN/KEY 和 STATE 不需要连接。

## 蓝牙通信

### 串口配置

|参数|配置|
|-|-|
|串口|USART1|
|波特率|9600|
|数据位|8 bit|
|校验位|None|
|停止位|1 bit|
|硬件流控|None|

### STM32 上传数据格式

STM32 周期性向手机发送温度、湿度、光照电压和阈值数据，例如：

```text
T:28.40RH:75.59LV:2.480TH:0.50
```

其中：

|字段|含义|
|-|-|
|T|温度，单位摄氏度|
|RH|相对湿度，单位 %|
|LV|光照电压，单位 V|
|TH|光照报警阈值，单位 V|

### 手机控制指令

|指令|功能|
|-|-|
|P|切换 OLED 页面|
|+|光照阈值增加|
|-|光照阈值降低|
|A|切换为自动报警模式|
|N|手动模式下打开蜂鸣器|
|F|手动模式下关闭蜂鸣器|

### 蜂鸣器控制逻辑

系统包含自动模式和手动模式：

|模式|逻辑|
|-|-|
|自动模式|当 `LV < threshold\\\_LV` 时蜂鸣器报警，否则关闭|
|手动模式|由手机指令 `N` 和 `F` 控制蜂鸣器开关|

## 使用方法

1. 上电后，OLED 显示传感器数据。
2. 旋转 EC11 编码器可切换 OLED 页面。
3. 在阈值页面按下按键进入编辑模式，旋转编码器调整光照阈值。
4. 手机连接 HC-05 后，可接收 STM32 上传的数据。
5. 手机发送 `P`、`+`、`-`、`A`、`N`、`F` 等指令可远程控制系统。
